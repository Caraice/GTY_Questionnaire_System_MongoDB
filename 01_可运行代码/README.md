# 基于 MongoDB 的问卷系统 · 第一阶段

这是一个简化的在线问卷系统，使用 **Python + FastAPI + PyMongo + 原生 HTML/CSS/JavaScript**，当前版本为 **0.8.0**。发布者可以创建、发布问卷并查看统计，填写者登录后通过分享链接作答、提交和回看自己的答案。业务数据统一存入 MongoDB，前端不需要额外构建。

## 已完成的功能

- 注册、登录、退出，以及不同账号之间的权限隔离。
- 单选、多选、文本、数字四种题型的编辑、排序和删除。
- 通过页面按钮配置跳转规则，按答案自动跳题，支持返回修改。
- 必答、选择数量、文本长度、数字范围和整数校验；合法的数字 `0` 正常保存和统计。
- 发布、关闭和修改截止时间，日期可手动输入或通过日历选择；发布后冻结题目与规则。
- 答卷真实保存，按设置支持匿名和多次填写；请求重试不会重复保存。
- 发布者查看整卷或单题统计，填写者查看本人已提交的内容。

## 怎么运行

先安装 Python 和 MongoDB。本机验证环境为 Windows、Python 3.14.6、MongoDB 8.0.17；Node.js 只用于前端测试。

**首次运行需要先安装依赖，直接双击 Start.cmd 可能会提示缺少 `.venv`。** 在本目录打开 PowerShell，执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt

# 换成自己电脑上的 mongod.exe 路径，再从同一个窗口启动
$env:MONGOD_EXE = 'C:\MongoDB\bin\mongod.exe'
.\Start.cmd
```

脚本会检查数据库连接并初始化集合与索引。默认网页是 [http://127.0.0.1:8000](http://127.0.0.1:8000)，MongoDB 使用本机 `27019` 端口和 `survey_stage1` 数据库。访问 [/health](http://127.0.0.1:8000/health) 可检查运行状态，版本应为 `0.8.0`。

依赖安装只需做一次。已有 MongoDB 可通过 `MONGODB_URI` 指定连接；Anaconda 安装问题及其他配置见 [配置说明](配置说明.md)。`.env.example` 只是参考，不会自动加载；重新解压或换电脑后，需要重新准备该目录的运行环境。

## 怎么使用

1. 注册并登录，在“创建问卷”保存草稿。
2. 点击“编辑题目”，保存后进入“配置跳转规则”；不需要跳题时可不添加规则。
3. 发布问卷并分享链接，填写者登录后按提示作答、确认提交。
4. 发布者点击“查看实时统计”，可切换整卷或单题；页面可见时每 10 秒刷新，也可手动刷新。
5. 填写者在“我填写的问卷”查看本人每次提交的内容，匿名记录也能回看。

截止或关闭后不能新增提交。已截止但未手动关闭的问卷可以延长期限；手动关闭后不能重新开放。修改冲突时页面会提示重新加载，避免覆盖别人的修改。日常操作通过网页完成，[/docs](http://127.0.0.1:8000/docs) 留作接口调试参考。

## 怎么测试

保持 MongoDB 可连接，并准备好 Node.js。从本目录进入测试文件夹运行：

```powershell
Set-Location ..\03_测试用例
powershell -NoProfile -ExecutionPolicy Bypass -File .\运行全部测试.ps1
```

脚本会启用真实 MongoDB 集成测试，并保存日志和 JUnit 结果。已有完整回归记录为 **2026-10-23：Python 283 项、Node 18 项通过，无失败和跳过**；这是历史实际结果，本次整理 README 未重新跑全套测试。具体步骤、输入输出和证据见 [测试步骤](../03_测试用例/测试步骤.md) 与 [测试结果](../03_测试用例/测试结果.md)。
